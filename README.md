# 薪流 SalaryFlow

Windows 本地个人预算、现金流、储蓄与理财资产管理应用。当前版本 **0.6.2**。无需账号，账本保存在本机，不连接银行、不自动转账。

## 当前版本重点

- 预算可按工资周期或自然月管理，规则支持立即、下周期或指定日期生效。
- 工资分配为独立页面，展示计算依据和余额；只在用户完成银行转账后记录，不会操作银行。
- 理财账户支持手工估值，市值涨跌改变资产余额但不计收入、支出、预算或储蓄率。
- 总览和账户金额支持全局与局部双层隐藏；预算卡按使用比例由绿到红。
- 统计支持趋势、环形图、收入/支出结构、前一等长区间比较和多种日期范围。
- 禁用控件及关键财务操作支持鼠标悬停与键盘聚焦说明，解释原因、恢复路径和资金影响。

## 开始使用

- [安装版 0.6.2 · Windows x64](https://github.com/XRosen26/SalaryFlow/releases/download/v0.6.2/SalaryFlow-Setup-0.6.2-x64.exe)：运行安装向导，选择安装位置。
- [免安装版 0.6.2 · Windows x64](https://github.com/XRosen26/SalaryFlow/releases/download/v0.6.2/SalaryFlow-Portable-0.6.2-x64.exe)：直接运行。这里“免安装”指程序无需安装，账本仍保存到用户数据目录，不跟随 EXE 移动。

首次启动设置工资日、记账起始日和账户期初余额，再检查预算。系统建议预算合计 ¥6,310，可自行修改，不代表你的真实工资或支出。实际用户账本不会自动填入测试交易。

安装包尚无公开代码签名证书，Windows 可能显示发布者未知。安装版和免安装版使用同一个用户账本；同一时刻只运行一个实例。已经存在的数据不会因升级重新初始化。

## 日常操作

1. **总览**查看本期收支、剩余预算、主要消费账户余额、可安心支出和待办账单。
2. **交易记录**记录工资、其他收入、支出、账户转账；从原支出发起退款。详情中修改、删除、查看历史，回收站可恢复。
3. **预算与周期**管理本期预算、个人默认预算及工资周期/自然月口径。已结算周期先重新打开并填写原因，再改历史数据。
4. **工资分配**从已标记的工资收入计算生活资金、储蓄和理财安排，完成真实银行转账后再记录。
5. **我的账户**新增、改名、设置类型和主要用途、调整排序、估值、校准或归档。有历史的账户保留记录。
6. **统计分析**选择工资周期、自然周/月/季度/年、滚动天数/月数或自定义日期；统计按交易实际日期计算。
7. **设置与数据**管理分类、固定账单、导入导出、备份、语言、配色和帮助。

工资分配生成计划，确认实际已完成的转账才记账；不会替你向银行发出转账。固定账单只是待办，确认支付或关联已有交易后才计支出。记账时请核对实际日期和账户。

应用内手册：**设置与数据 → 帮助与使用手册**，可搜索、展开阅读，并查看测试账本示例截图。固定账单页区分待办、处理历史与规则，未来规则显示下次到期日。

语言路径：**设置与数据 → 偏好设置 → Interface language**，选择中文或 English。切换后界面重新载入；系统预置账户、类型和分类按界面语言显示，SQLite原值不变；用户自定义名称和备注保持原文。浅色、深色模式独立保存。

## 金额与统计口径

金额存为整数“分”。金额框可直接输入 `+ - * / ( )` 算式并预览结果，例如 `12.5+8+6*2`；普通金额最多两位小数，算式只在最终结果四舍五入到分。合并输入保存为一笔交易，需要分别分析时应逐笔记账。转账只保存一笔交易，同时影响两个账户，不计全账本收入或支出。期初余额和余额校准也不计收入。

净支出 = 支出 − 到账退款；净结余（储蓄）= 收入 − 净支出。新增支出或转账默认拦截付款账户余额不足；预算超支本身不阻止保存。历史补录可在偏好设置明确允许负余额。收入大于零时，储蓄率 = 净结余 / 收入；否则显示无适用值。把钱移到储蓄账户不重复增加储蓄。退款按实际到账日冲减当期，可分次退但不能超过原支出。

预算口径可选择工资周期或自然月。工资周期按计划工资日划分，月底短月取最后一天；规则可立即、下周期或指定日期生效，系统会阻止排除既有交易的不安全重划。系统初始预算、个人默认和周期预算各自保留版本。修改历史交易会重算余额与相关统计；余额校准的历史差额不会自动变化来抵消后续补录。

## 数据、备份和恢复

默认目录：`%APPDATA%\SalaryFlow`，主数据库为 `ledger.sqlite`。在设置与数据 → 数据管理 → 迁移数据目录中选择父目录，应用创建 `SalaryFlow-data`，校验副本后重启。可选择软件所在目录（需可写），原账本保留；默认用户目录留有小型 `location.json` 路径配置，目录移动后不会自动跟随。已有目标账本不覆盖，自定义磁盘断开时停止启动以避免出现误导性的空账本。单独设置过的自动备份目录仍保留原选择。可在应用中打开数据目录。账本和备份**未加密**，应使用自己的 Windows 账户并妥善保管副本。

应用运行期间检查自动备份，数据有变化时生成快照；默认保留最近 30 个日期的日备份及 12 个月的月备份，可选择其他磁盘目录。程序关闭时不执行后台备份；同一硬盘的备份无法抵御整块硬盘故障。

建议在大量修改前使用“立即备份”，保留生成的 `.sqlite` 文件及同名 `.json` 校验清单。恢复是**整体替换**：先另存当前安全快照，再校验选中备份并恢复，不能与当前账本自动合并。升级数据库前同样生成安全副本，失败不提交迁移。

若应用因主数据库损坏无法启动：先退出程序，将整个数据目录复制到安全位置；保留损坏文件供排查。使用已验证的备份进行恢复，不要直接覆盖仍在运行的数据库，也不要随意删除 `-wal` 文件。可在保留原目录后将其改名，重新启动创建空账本，再从应用内恢复备份。

## 导入与导出

- **CSV**：用于可阅读交易明细及增量导入。导入先匹配字段、账户和分类，检查预览及错误再提交。外部交易号用于强去重；同日同额只提示疑似重复，仍可能是真实的两笔交易。支持撤销导入批次，但有后续依赖时会阻止撤销。
- **完整 JSON**：带版本及 SHA-256 的完整 SQLite 快照数据包，数据库内容使用 Base64，保留审计、预算版本和已删除记录。用于完整数据恢复，不是手工编辑或增量合并格式。
- CSV 导出旁的 `.metadata.json` 记录统计范围及口径；CSV金额单位为元，接口语言切换不会改变中文字段名称这一数据格式约定。字符串有公式注入保护。

Excel、Markdown、微信/支付宝专用导入适配器在后续范围。通用 CSV 可先预览映射，不能假定任意银行账单直接兼容。

## 开发与维护

技术：Electron + React + TypeScript + Vite，主进程 Node SQLite，本地 SVG 图表。先安装兼容的 Node.js 24，再执行：

```powershell
npm ci
npm start
npm test
npm run test:desktop
node scripts/language-test.mjs
npm run dist
```

`npm start` 构建并启动桌面程序；单独 `npm run dev` 只提供界面开发服务器，不能替代桌面 SQLite 运行环境。自动化桌面测试使用独立测试数据目录，不写真实账本。首次安装依赖和打包工具需要联网，安装后的应用离线运行。

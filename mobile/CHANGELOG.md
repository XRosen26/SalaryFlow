# 薪流移动端更新日志

## 0.5.0 预览 — 2026-09-14

- 统计增加今日与最近3天范围；交易明细增加快捷/自定义日期和最低/最高金额筛选，并在SQLite查询层与类型、搜索、排序组合执行。
- 记账分类改为“点击展开弹层、选择后自动收起”，保留图标与分组；付款/收款账户同样使用动态弹层，避免列表过长。
- 首页预算卡在预算用完或超支后切换标题、金额和提示，颜色继续复用七级预算风险规则。
- 新增待收款：记录对方、借出账户、可选归还日和备注，支持逾期提示、分次归还及选择回款账户；借出/归还不计收支、预算和储蓄率。
- 移动数据库升级至schema 2；完整备份增加待收款表，并兼容旧版无待收款数据的备份。
- Android/iOS继续共用Expo工程；增加iOS Bundle ID、构建号、系统本地化名称和平板配置，iOS bundle导出通过。IPA仍需macOS/Xcode签名。
- 移动端版本更新至0.5.0，Android versionCode更新至5。

## 0.1.0 MVP 预览 — 2026-09-12

### 已完成

- 在同一仓库建立独立 `mobile/` 子项目，使 Android 与 Windows 端共享产品规则并保持独立构建。
- 完成首次设置、首页、明细、中央快速记账、预算、账户、设置与数据的移动信息架构。
- 支持收入、支出、转账、关联退款、修改和软删除；余额不足会显示具体缺口并阻止保存。
- 所有金额以整数分保存；金额框支持 `+ - * / ( )`，使用自建解析器计算，不执行输入代码。
- 支持系统初始化预算、个人默认预算和当前周期预算；当前周期修改可选择是否同步个人默认值。
- 支持工资周期和自然月，周期规则可立即、下周期或指定日期生效；交易按实际发生日期匹配周期。
- 支持动态账户、独立金额隐藏、工资/主要消费/主要储蓄角色和理财账户市值快照。
- 支持动态收支分类及历史版本；“其他”只是可编辑的默认分类。
- 完成工资分配助手：显示工资、工资账户余额、消费账户余额、预算缺口、来源上限和资金缺口；确认后原子写入真实转账。
- 完成固定账单：支持多条月度/周度账单、确认支付和跳过本期；未确认前不计支出。
- 完成统计分析：按实际日期查看当前周期、最近 30 天和自然月的收入、净支出、储蓄率、分类圆环图和每日趋势。
- 完成带 SHA-256 的完整 JSON 备份、摘要预览、恢复点、外键/数据库完整性校验、原子恢复和清空账本。
- 新增中文使用说明和“关于”，作者信息为“由 XRosen26 使用 Codex 完成产品设计与开发”。
- 完成薪流专用应用图标、浅色/深色和响应式卡片布局。

### 可靠性与隐私

- 带退款的支出不能改为其他交易类型；累计退款不得超过原支出。
- 转账不计收入、支出或储蓄率；退款按实际日期冲减净支出；修改交易会重新匹配预算周期。
- 理财涨跌只进入资产估值，不伪装成收支；同日资金移动后再记录当日市值。
- 恢复前创建本地恢复点，导入校验失败会整笔回滚。
- release 清单移除联网、悬浮窗和旧外部存储权限；Android 系统云备份关闭，最终只保留震动权限。
- 清理未引用的 Expo 模板图片、编辑器配置、脚本和直接依赖；安装包不含数据库或个人数据。

### 迭代问题与判断

- 中文源码路径会让 NDK/CMake 失败，因此构建脚本复制干净源码到固定短英文目录；该目录在递归清理前进行绝对路径核对。
- 同时构建 ARM64 与 x86_64 时，Windows 的 CMake/Ninja 出现重生成循环及 260 字符路径限制。首个可用包聚焦现代安卓真机的 ARM64；x86_64 仅在模拟器验收需要时单独构建。
- 多设备实时同步会引入身份、加密、冲突和重复交易问题。0.1.0 使用完整备份整库替换，界面明确说明不会合并两端修改。
- 未对 npm 的 15 项中等级传递依赖告警执行 `--force` 升级，因为强制跨主版本会破坏 Expo SDK 57 的已验证依赖组合；后续随 Expo 官方兼容版本升级处理。

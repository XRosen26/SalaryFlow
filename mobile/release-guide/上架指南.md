# SalaryFlow iOS 测试与发布指南

SalaryFlow 的 Android 与 iOS 端共用 `mobile/` 下的 Expo/React Native 业务代码。当前 iOS 配置为版本 0.6.1、buildNumber 8、Bundle ID `com.xrosen26.salaryflow`。

Windows 不能安装或运行 Xcode，也不能在本机完成 Apple 原生编译与签名。可以从 Windows 发起 EAS 云构建，由云端 macOS 环境生成 IPA；签名和真机分发仍受 Apple 账号与证书规则约束。

## 选择测试方式

| 方式                  | 需要 Mac            | 需要付费 Apple Developer | 适用场景                                        |
| --------------------- | ------------------- | ------------------------ | ----------------------------------------------- |
| Expo Go               | 否                  | 否                       | 开发阶段快速真机预览，不生成独立 IPA            |
| EAS Internal / Ad Hoc | 否                  | 是                       | 给已登记设备安装独立测试包                      |
| TestFlight            | 否，可用 EAS 云构建 | 是                       | 多人、较长期测试及上架前验收                    |
| Xcode Personal Team   | 是                  | 否                       | 在 Mac 上安装到本人设备，免费签名通常需定期重签 |

测试安装不必先公开上架 App Store。直接分发 IPA 时仍必须使用有效签名；把未签名 IPA 文件直接发给 iPhone 无法安装。

## Windows 上准备 EAS

在 PowerShell 中进入本仓库的 `mobile` 目录：

```powershell
npm ci
npx eas-cli@latest login
npx eas-cli@latest config
```

首次使用需要注册 Expo 账号。EAS 构建会上传源码和构建资源；`.easignore` 已排除依赖、缓存、发布包和本地数据。项目本身不应包含任何个人账本。

## 免费预览：Expo Go

1. 在 iPhone 从 App Store 安装 Expo Go。
2. Windows 与 iPhone 连接同一网络。
3. 在 `mobile` 目录运行 `npx expo start`。
4. 用 Expo Go 扫描二维码。

Expo Go 适合检查页面与交互，不等同于最终独立安装包，也不能替代正式签名包的完整验收。

## 独立内测包

使用已加入 Apple Developer Program 的账号，并先登记测试设备：

```powershell
npx eas-cli@latest device:create
npx eas-cli@latest build --platform ios --profile preview
```

EAS 会在云端 macOS 环境完成编译和签名。构建完成后按 EAS 提供的链接安装；未登记设备不能安装 Ad Hoc 包。

## TestFlight 与正式发布

```powershell
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --profile production
```

上传后在 App Store Connect 中配置测试人员、隐私信息、截图和版本资料。TestFlight 外部测试及正式上架可能需要 Apple 审核。Apple Developer Program 费用、地区税费和分发规则以 Apple 当时公布的信息为准。

## 发布前检查

- 在真机验证启动、快速记账、键盘避让、日期选择、备份恢复和深浅主题。
- 检查大字体、横竖屏、刘海与底部安全区。
- 确认版本号、buildNumber、图标、中文与英文系统名称。
- 使用空白测试账本构建；发布包和代码仓库不得包含个人数据库或备份。
- 正式发布前重新运行 `npm run check` 和 iOS bundle 导出。

# 薪流移动端产品与交互设计

## 0.6.1 状态说明与修复入口（2026-09-16）

固定账单页同时承担规则管理和到期待办：用户可以修改规则，变更只作用于当前未确认待办与未来计划；删除采用停用规则并取消未确认待办的方式，已支付历史和真实交易不被改写。

首页必须使用数据库实际角色 `PRIMARY_SPENDING` 判断主要消费账户。缺少主要消费账户、缺少当前预算或主要消费账户余额不足属于不同状态：卡片分别说明原因，并提供直达账户或预算页面的按钮；已正确设置时不得继续显示配置提示。

## 0.6.0 安心支出与历史周期选择（2026-09-16）

首页总览卡的可用金额取本期剩余预算与主要消费账户余额中较小的非负值。颜色和状态文案也同时参考两项约束，以更紧张的一项为准；预算用完、已经超支、未设置主要消费账户或账户余额不足时分别给出明确说明。预算列表继续按各分类的预算执行率着色，两者表达的对象不同。

统计保留今日、近3/7/30/90天、工资周期和自定义日期，并增加周、月、年历史周期列表。历史列表从首次记账所在周期开始生成，当前与上一周期使用自然称呼，更早周期显示年份和ISO周/月；每项同时展示完整起止日期。

## 0.5.0交互补充

记账以短页面完成高频路径：先选类型，点击分类打开底部弹层，选中后自动收起并聚焦金额；账户使用相同模式。交易明细的范围面板默认收起，可选今日、近3/7/30天、自定义日期和金额上下限。首页预算卡在额度用完或超支后改为明确提醒。

## 1. 信息架构

手机底部导航固定五个入口：

| 一级入口 | 核心内容                                 | 二级页面                         |
| -------- | ---------------------------------------- | -------------------------------- |
| 首页     | 当前可安心支出、本期预算、近期交易、账单 | 分析、工资分配、账单、帮助       |
| 明细     | 搜索、筛选、流水列表                     | 交易详情、编辑、退款、修改历史   |
| 记一笔   | 支出/收入/转账/待收款                    | 分类选择、账户选择、保存结果     |
| 预算     | 周期摘要、分类预算执行                   | 当前预算、个人默认预算、周期设置 |
| 账户     | 总资产、账户卡片                         | 账户详情、新增/编辑、估值、校准  |

“更多”不占用底部标签。首页顶部依次提供金额显示、使用说明和设置；帮助页包含“使用说明/关于”，设置集中放置周期、分类、账单、账户、外观、隐私和数据管理。当前版本在宽屏上调整卡片列数和间距；600dp 以上侧边导航及列表—详情结构列入平板专项适配。

## 3. 高频流程

### 快速支出

点“记一笔”或首页“支出” → 选择交易类型 → 按分组和图标选择分类 → 输入金额/算式 → 选择账户 → 用日历选择或输入实际日期 → 可选备注 → 保存 → 震动和结果提示。转账没有分类，选择类型后直接填写金额和账户。余额不足时，保存按钮保持可点但点击后展示具体缺口和可调整入口，不静默失败。

### 工资到账与分配

记录收入并勾选“这是工资” → 保存成功页显示“制定工资分配” → 进入工资分配页。页面说明预算总额、消费账户当前余额、应补足金额、分配上限的来源（本次工资/工资账户可用余额/自定义）和剩余可储蓄。确认计划后，用一组带同一 `operation_id` 的转账写入；失败则整组回滚。

### 退款

从原支出详情进入退款 → 默认全部退款，可点 25%/50%/75%/全部或输入算式 → 选择入账账户和日期 → 保存。累计退款不得超过原支出；退款使用原分类版本并关联原交易。

### 数据迁移

设置与数据 → 创建完整备份 → 系统分享面板。另一设备选择恢复 → 先显示版本、创建时间、实体数量和余额摘要 → 自动生成恢复点 → 替换账本 → 重启查询并对账。第一阶段明确提示“整库替换，不会合并两台设备的修改”。

## 4. 触屏与可访问性

- 主要触控目标至少 48×48dp，操作间距至少 8dp。
- 页面主要按钮在单手拇指易达区域；表单提交随键盘上移，不被遮挡。
- 颜色只作为辅助，同时显示数字、文字状态和图标。
- 金额默认使用等宽数字；隐藏后保持卡片布局稳定。
- 弹出说明使用可点击问号并支持长按/读屏；不依赖只能悬停的交互。
- Android 系统返回键先关闭键盘/弹层，再回到上级；不在无提示时丢弃表单。

## 5. 视觉规范

- 主色：松柏绿 `#176B55`；背景 `#F5F7F4`；卡片 `#FFFFFF`；正文 `#17221E`。
- 危险/超支：`#C53D3D`；警告：`#C17817`；信息：`#2866A9`。
- 预算从绿到红按净支出比例分段，并始终配套“正常/接近/已用完/超支”文字。
- 圆角 16dp（卡片）、12dp（输入）、999dp（标签）；阴影克制，以边框分层。
- 间距采用 4/8/12/16/24/32；页面水平边距手机 16dp、平板 24dp。
- 字号：标题 28、页面段落 16、正文 15、辅助 12；金额主数字 32。

## 6. 空态、错误与离线

- 空态说明下一步并提供唯一主操作，如“还没有交易—记第一笔”。
- 数据库错误展示重试和导出诊断；不把数据库内部错误直接暴露给用户。
- 所有核心功能离线可用；联网功能出现时必须标记网络状态和失败后果。
- 保存采用防重复操作 ID；连续点击或应用恢复不得重复写入。

## 7. 0.3 视觉与高频录入完善

- 外观设置提供六套完整配色。业务风险色仍按预算使用率表达，基底色会与当前配色协调，并分别适配浅色/深色背景。
- 首页总览卡使用双约束状态：可用金额、颜色和提示同时参考剩余预算及主要消费账户余额，以更紧张的一项为准；预算列表使用 `budgetTone` 表达单个分类的预算执行率。
- 快速记账不截断分类：按分类组显示全部启用项，以图标帮助扫视、文字保证含义；用户可直接进入分类管理。
- 启动器图标采用稳定的 S 形资金流标志。预算比例属于变化频繁的私密状态，不写入系统启动器图标。
- 启动器短名称按系统语言资源本地化；应用内语言偏好后续实现时，不承诺即时重启系统桌面进程。
